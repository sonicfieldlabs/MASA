# Sonification system adapter archetype

Placeholder namespace: `sonify:`

A data sonification system uses the Mapping profile to keep source observation, derived index, normalization, parameter mapping, synthesis, performance, and speculation distinct.

Every replayable control should trace to source evidence, an authored mapping, performer action, declared nondeterminism, or an explicit missing-data operation. API health and freshness do not become confidence. Missing or stale values must be skipped, held, interpolated, rendered as uncertainty, or refused explicitly; they never silently become zero.

Planetary or cosmic scale is a declared scope, not universality, and sonification is an authored material relation rather than the source's literal voice.
