# Studio application adapter archetype

Placeholder namespace: `studio:`

An interactive studio or workstation application reads Core, Audio, Listening, Analysis, and Transformation records, then adds its own cards, views, DSP state, and analytical affordances under its application namespace.

A first integration of this shape must prove:

- lossless import of a source Representation and unknown extensions;
- regions and measurements with units, methods, windows, and uncertainty;
- listening passes kept distinct from automated analysis;
- transformations producing new Representation identifiers, parent relations, and receipts;
- policy refusal producing no fabricated output;
- public projection excluding private media, paths, and provider state.

An interface may visualize a MatterRecord but must not treat the record as the sound itself.
