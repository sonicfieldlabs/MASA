# Core profile 0.1.0

The Core profile is required by every MatterRecord. It provides identity, actors, at least one representation, policy state, claims, relations, operation history, disclosure, integrity, and extensions.

Core is deliberately small enough for a conventional script. It does not require audio decoding, human listening, signal analysis, generation, mapping, agents, or publication.

Conformance requires the Core schema and every semantic invariant in `../core.md`.
